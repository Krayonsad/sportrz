# Sportrz (Next.js Rebuild)

Rebuilding [sportrz.com](https://sportrz.com) using a modern frontend stack to support game catalog browsing, subscriptions, user accounts, and personalized recommendations.

## 🚀 Project Goal

To transition Sportrz from WordPress to a scalable, performant, and user-friendly web platform built with Next.js.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Hosting**: Vercel (Frontend), Supabase/Neon (Database)

## 📦 Features

- 🔍 Game Catalog (500+ games)
- 🔑 Login & Signup
- 👥 User Profiles & Friends
- 🎯 Game Recommendations
- 💳 Subscription System (e.g., one-day pass)
- 🌍 Multi-country support (10+)
