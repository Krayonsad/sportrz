# Project Idea – Sportrz Web App

## 🎯 Vision

Build a modern web application to showcase and sell access to 500+ games to users primarily in African countries, using a flexible subscription model.

## 📌 Key Objectives

1. Migrate current WordPress-based site to a scalable Next.js environment.
2. Support users from 10+ countries.
3. Introduce user authentication and profiles.
4. Improve UX with responsive, fast frontend.
5. Enable a "1-day pass" subscription system to access any game.
6. Add recommendation logic based on preferences/friends.

## 🧑‍💻 Target Audience

- Gamers or customers in Africa interested in short-term access to multiple games.
- Users with low commitment budgets (e.g., daily pass).
- Communities that share games with friends and want personalized suggestions.
